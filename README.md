# Zay-Marie Press

Official website repository for Zay-Marie Press.

This repository contains the production website files for zaymariepress.com.

## Digital study publishing workflow

1. Audit the final study PDF and controlling doctrinal framework.
2. Recommend the detail-page narrative, preview pages, and catalog-card copy.
3. Discuss revisions and obtain explicit approval before implementation.
4. Build the detail page to the approved Studies 1–3 benchmark. One of the four purchaser-facing preview pages must be the study’s “What You Will Learn in This Study” page; do not use the Table of Contents in its place.
5. Verify that the catalog-card description accurately reflects the detail page and matches the Study 1–2 benchmark for specificity, doctrinal accuracy, narrative depth, and robustness.
6. Publish through `main`, verify the live page, and request final visual review.
