Study 88 build recipe. content.txt is the interior in the builder's markup; build88.py builds the DOCX (python-docx), tocpass.py reads the rendered PDF and writes toc.json (interior page numbers, TOC = PDF page − 1). Run twice with tocpass between: `python3 build88.py content.txt toc.json p.docx; soffice --headless --convert-to pdf p.docx; python3 tocpass.py p.pdf` (fonts via fc.conf, Roboto from /fonts). cover_supplied.jpg is the publisher's supplied cover (1600×2400); genpage88.py generates the study page from the Study 87 page. KJV text was checked against Bible Gateway KJV and the repo corpus (see CLAUDE.md v1.171).
